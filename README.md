# iOS & iPadOS 27 UI Kit — Developer Reference

A self-contained HTML reference page for the iOS & iPadOS 27 UI Kit, generated from Figma.

## What's included

- **Design Principles** — Liquid Glass, Light/Dark Mode, Dynamic Type, Semantic Tokens, Safe Areas, SF Symbols
- **Color Tokens** — All 63 semantic color variables with Light & Dark mode RGB values
- **Typography** — 12 SF Pro text styles with sizes, weights, leading, and tracking
- **Variable Collections** — 6 collections (Colors, Icons, Dimensions, Dynamic Type, Text Leading, Kit)
- **Component Library** — 55 public components organized by category with variant counts
- **Variant Properties Reference** — 20 key components with all configurable properties
- **Device Bezels** — iPhone 17 Pro/Max, iPhone 17, iPhone Air, iPad Pro M4

## Usage

Open `index.html` in any browser. The page automatically adapts to your system's Light/Dark mode preference.

## Deploy with GitHub Pages

1. Go to your repo **Settings** → **Pages**
2. Under **Source**, select **Deploy from a branch**
3. Choose **main** branch and **/ (root)** folder
4. Click **Save**

Your site will be live at `https://mcarrollnow.github.io/ios27-developer-reference/`

## Other deployment options

This is a single static HTML file with zero dependencies:
- **Netlify / Vercel** — Drag and drop the repo
- **Any static host** — Just serve `index.html`
