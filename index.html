Design Principles

Key principles from Apple Human Interface Guidelines for iOS & iPadOS 27

Liquid Glass

iOS 27 introduces Liquid Glass — a translucent material creating depth and layering. It adapts to content behind it and shifts between light/dark. Use Liquid Glass components for a fluid, spatial interface.

Light & Dark Mode

Every component supports both Light and Dark appearances. The Colors variable collection provides semantic tokens (Backgrounds, Labels, Fills, Accents) that automatically adapt. Use variable modes — never hardcode colors.

Dynamic Type

Support all 12 Dynamic Type sizes (xSmall → AX5). The Dynamic Type variable collection scales font sizes and line heights automatically. Text styles use SF Pro with precise tracking. Always test at multiple sizes.

Semantic Color Tokens

Use semantic tokens: Labels/Primary for text, Backgrounds/Primary for surfaces, Fills/Primary for tinted fills, Accents/Blue for interactive elements. Elevated variants exist for content above the base layer.

Safe Areas & Layout

Respect safe area insets on all devices. The Dimensions variable collection provides iPhone vs iPad values. Home Indicator and Status Bars occupy system-reserved regions.

SF Symbols

Use SF Symbols for all iconography. They scale with Dynamic Type, support variable rendering, and adapt to weight. Install the SF Symbols app for the full catalog.
